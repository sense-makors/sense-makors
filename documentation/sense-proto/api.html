HTTP API

Sense-Proto clients talk to a Solid pod over HTTP. This page lists the routes implemented by OpenID (Hewlbern/openID). Paths and fields below are the ones its functional tests and README call. Routes that are not in that server are not listed here.

Two processes

The long-lived Go server owns the pod volume. The passport UI can proxy identity calls. Local examples in this documentation use the Go server on http://localhost:3000.

Identity

RequestRole
GET /healthLiveness. Body is {"status":"ok"}.
GET /.well-known/openid-configurationOIDC discovery document. Includes issuer and token_endpoint.
GET /.well-known/solidSolid storage description.
POST /idp/registerCreate an account and, with createPod: true, a pod.
POST /idp/loginPassword login. Returns a Bearer token.
POST /idp/client-credentialsMint a machine client. Body {"name":"bot"} returns id and secret.
POST /oauth/tokenExchange grant_type=client_credentials for access_token.
POST /agentsRegister an AI agent. Body {"name":"Atlas"}. Response includes token, agent.webId, agent.podPath, agent.publicKey, and privateKey.
GET /agentsList registered agents.

Pod resources

Resource URLs accept GET, HEAD, PUT, POST, PATCH, DELETE, and OPTIONS.

  • Containers end with / and their Turtle body uses ldp:contains.
  • Create a container with Link: <http://www.w3.org/ns/ldp#BasicContainer>; rel="type".
  • POST to a container accepts a Slug header. The response is 201 with a Location header.
  • PATCH accepts Content-Type: application/sparql-update or text/n3. OPTIONS advertises sparql-update in Accept-Patch.
  • ACL documents live at {resource}.acl or {container}/.acl. A successful GET includes Link with rel="acl".
  • Conditional writes use If-Match and If-None-Match. A stale If-Match returns 412.

GET /mcp and POST /mcpMCP endpoint for a connected agent. A local server also answers go run ./cmd/mcp over stdio when OPENID_BASE_URL is set.

Worked example: register, then write a note

Register with a pod. The functional test reads token, webId (it contains profile/card#me), and account.podPath from this response:

curl -s -X POST http://localhost:3000/idp/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"ada@example.com","password":"testpass123","name":"Ada","createPod":true}'

Save the token value, then create a text resource. The same test expects 201 on create and the plain-text body on the following GET:

curl -i -X PUT http://localhost:3000/workspace/note.txt \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: text/plain' \
  --data 'hello functional'

curl -s http://localhost:3000/workspace/note.txt
# hello functional

A PUT of the same URL with no Authorization header returns 401. Repeating registration for an existing account returns 409.
