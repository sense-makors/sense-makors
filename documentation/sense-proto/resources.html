Worked example: confirm the server you cloned

After cloning OpenID, this is the health check from its README. A running server answers with that JSON and nothing else on this route:

git clone https://github.com/Hewlbern/openID.git
cd openID
go run ./cmd/server -port 3000 -storage ./data

curl -s http://localhost:3000/health
# {"status":"ok"}

Discovery documents, which the functional test also fetches, are GET /.well-known/openid-configuration and GET /.well-known/solid. Both return 200 on a server started this way. Continue with Authentication to turn that process into an account and a WebID.
