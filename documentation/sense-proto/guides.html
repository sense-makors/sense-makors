Guides

These guides walk through a Solid pod, a WebID, and the HTTP calls that read and write it. The server used in the examples is OpenID, the Go Solid server in Hewlbern/openID. Each guide below is a page on this site.

Start here

Run the server, then follow one guide. The commands in the worked example are the same ones in the OpenID README.

Guide index

Worked example: start the server and check it

From a checkout of github.com/Hewlbern/openID:

git clone https://github.com/Hewlbern/openID.git
cd openID
go run ./cmd/server -port 3000 -storage ./data

The process listens on port 3000 and stores pod files under ./data. The health route returns JSON:

curl -s http://localhost:3000/health
# {"status":"ok"}

The console is http://localhost:3000/. The handle-claim page is http://localhost:3000/welcome. After this check, register an account with the example on the Authentication page, or read the route list on the API page.
